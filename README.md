# Human & AI: An Interactive Book

A comprehensive Next.js application exploring the relationship between humans and artificial intelligence.

## Features

- **100 Pages of Content**: Comprehensive coverage of AI history, ethics, and future
- **Interactive Chatbot**: Get answers to your questions about human-AI interaction
- **Smart Search**: Quickly find topics across all chapters
- **Modern Design**: Built with Next.js for fast, responsive reading

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser

## Project Structure

- `pages/` - Next.js pages including book chapters
- `components/` - Reusable components (Layout, Chatbot)
- `styles/` - CSS and styling
- `public/` - Static assets

## Book Chapters

- Introduction: The Convergence of Human and Machine
- Chapter 1-10: Comprehensive exploration of AI topics
